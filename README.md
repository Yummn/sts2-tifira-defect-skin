# 蒂菲拉故障机器人皮肤增强版

这个 MOD 把《杀戮尖塔 2》的故障机器人替换成《卡厄斯梦境》的蒂菲拉，并在原皮肤包基础上补充了选角背景、战斗动作、左侧 Battle Ready 演出和语音触发。它只改变视觉与音频表现，不修改卡牌数值或玩法规则。

## 主要内容

- 选角界面的蒂菲拉主题形象与可切换背景。
- 战斗、商店和休息场景中的 Spine 角色替换。
- 卡牌真正进入出牌区或目标选择后才触发的 Battle Ready 演出；普通查看卡牌不会触发。
- 攻击、防御、施法、充能球、受击和胜利等动作与原资源包语音的对应。
- 针对手机端的按需加载、音频播放器复用和重复动作合并，降低快速出牌时的瞬时开销。

当前版本为 [v1.1.9](https://github.com/Yummn/sts2-tifira-defect-skin/releases/tag/v1.1.9)。这一版恢复了完整待机动画，同时让手机端在提交卡牌时关闭大型 Battle Ready 骨骼、错开角色动作和常用语音预热，并保证胜利动画与语音每场只触发一次。

## 安装

从 [GitHub Releases](https://github.com/Yummn/sts2-tifira-defect-skin/releases) 下载与游戏版本匹配的 ZIP，解压后把完整的 `TifiraDefectSkin` 文件夹复制到游戏的 `mods` 目录。安装包同时包含 DLL 与 PCK，不能只复制其中一部分。

## 资源与署名

- 原始资源包 / MOD：`蒂菲拉故障机器人皮肤-v1.0.14.zip`
- 原作者 / 来源标注：`B站/抖音：异色缸墨灵`
- 兼容与演出增强维护：Yummn

角色图片、Spine、音频等素材来自原资源包。本仓库的增强部分主要是触发逻辑、manifest、打包和跨版本兼容，不改变原素材的归属。

## 开发说明

增强逻辑位于 `TifiraDefectSkinCode/`，项目入口为 `TifiraDefectSkin.csproj`。仓库中保留的部分场景、脚本和音频并不会由当前 DLL 主动触发，它们属于原资源包或兼容留档，不代表每项都已接入游戏。
